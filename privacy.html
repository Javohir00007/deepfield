Privacy Policy

Last updated: October 25, 2026

The Deep Field uploader is a private tool used only by the owner of the Deep Field YouTube channel to upload, schedule and manage videos, thumbnails, captions, playlists and comment replies on that channel.

What data the tool uses

With the owner's permission, the tool uses Google OAuth to access the owner's own YouTube channel through the YouTube Data API. It stores an OAuth refresh token locally on the owner's computer. It does not collect, sell or share personal data of any other person.

Google user data

Data obtained from Google APIs is used only to manage the owner's own channel. It is not transferred to third parties, not used for advertising, and not used to train AI models. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the local token file removes all stored data.
